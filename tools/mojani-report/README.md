# मोजणी नकाशा → मूल्यांकन अहवाल (mojani-report)

भूमि अभिलेख कार्यालयाचा **पोटहिस्सा मोजणी नकाशा (PDF)** घेऊन त्यातून ग्राहकाला देण्यायोग्य
अहवाल तयार करणारी साखळी — बाजूनिहाय मापे, प्रत्येक हिस्स्याचे क्षेत्रफळ, प्रमाणबद्ध नकाशा,
त्रिमितीय दृश्य, चतु:सीमा आणि Excel तक्ते.

पहिला अहवाल: **सि.स.नं. 2457, मौजे हुपरी, ता. हातकणंगले, जि. कोल्हापूर** (मो.र.नं. 090729/2025).

## हे का चालते

मोजणी नकाशे हे scanned चित्र नसून **vector PDF** असतात — हद्दरेषा खऱ्या भूमितीसह साठवलेल्या
असतात आणि नकाशावर प्रमाण (उदा. 1:500) दिलेले असते. त्यामुळे:

```
1 PDF point = 25.4/72 मिमी × 500 ÷ 1000 = 0.176389 मीटर
```

या एका गुणकावरून प्रत्येक बाजूची लांबी आणि shoelace सूत्राने क्षेत्रफळ काढता येते.
2457 च्या बाबतीत असे काढलेले क्षेत्र **298.55 चौ.मी.** आले, तर नकाशावरील अधिकृत आकडा
**299.20 चौ.मी.** — फरक फक्त **0.22%**. म्हणजे पद्धत विश्वासार्ह आहे.

> मोजणी नकाशावर बाजूंची मापे आकड्यांत लिहिलेली नसतात. ती इथे भूमितीवरून काढली जातात,
> म्हणून अचूकता साधारण **± 0.5 फूट (± 0.15 मी.)** धरावी. दस्त नोंदणी किंवा बांधकामापूर्वी
> जागेवर टेप/DGPS ने पडताळणी सांगावी — हे अहवालातही स्पष्ट लिहिलेले आहे.

## नवीन प्लॉटसाठी पायऱ्या

```bash
pip install -r requirements.txt

# 1. PDF मधून हद्दरेषा व मजकूर काढा
python3 extract_pdf.py नवीन-नकाशा.pdf --paths --min-width 0.6

#    सर्वात जाड बंद polyline = मुख्य हद्द. तिचे कोपरे टिपून घ्या.
#    तुटक (dashed, width ~0.24) रेषा = पोटहिस्सा सीमांकन.

# 2. mkplan.py / mkiso.py मधील V{}, POLY{}, AREA{}, OWNER{} बदला
#    build.py मधील MAIN, SUB, चतु:सीमा व मोजणी तपशील बदला

# 3. संपूर्ण अहवाल तयार करा
./run.sh
```

## फाइल्स

| फाइल | काम |
|---|---|
| `extract_pdf.py` | PDF मधून मजकूर + हद्दरेषा, प्रत्येक बाजूची लांबी मीटर/फूटात |
| `mkplan.py` | प्रमाणबद्ध नकाशा — आडवा (वेब) व उभा (A4 छपाई), सर्व मापे नकाशावरच |
| `mksvg.py` | प्रत्येक पोटहिस्स्याचे स्वतंत्र चित्र, सर्व बाजू मापांसह |
| `mkiso.py` | त्रिमितीय (isometric) दृश्य — SketchUp शैली |
| `build.py` | संपूर्ण HTML अहवाल (`--portrait` = छपाईची आवृत्ती) |
| `makeprint.py` | A4 उभ्या छपाईसाठी CSS + पान-विभाजन |
| `xl.py` | Excel तक्ते — सारांश, मुख्य बाजू, पोटहिस्सा बाजू, नोंदी |
| `georef_overlay.py` | उपग्रह प्रतिमेवर हद्द बसवणे + GeoJSON |
| `valuation.py` | पोटहिस्सानिहाय शासकीय (रेडी रेकनर) व बाजार मूल्य |
| `run.sh` | वरील सर्व एका आज्ञेत |

## उपग्रह overlay

मोजणी नकाशा स्थानिक ग्रिडवर असतो — त्यात अक्षांश-रेखांश **नसतात**. पण नकाशावर **प्रमाण
(1:500)** आणि **उत्तर बाण** असतो, म्हणजे scale व rotation आधीच माहीत असतात. त्यामुळे:

* **एकच lat/lon पुरे** (`anchor` पद्धत) — कोणत्याही एका कोपऱ्याचे GPS. संपूर्ण हद्द तेवढीच
  अचूक येते जेवढा तो एक बिंदू (मोबाईल ± 3–5 मी.).
* **दोन बिंदू दिल्यास** scale व rotation पडताळले जातात — स्क्रिप्ट *जमिनीवरील scale* छापते;
  तो 1.0000 च्या जवळ नसेल तर GPS किंवा कोपऱ्याचे नाव चुकले आहे. शक्य असल्यास हेच वापरा.
* GPS शक्य नसेल तर महाभूमी **भू-नकाशा** पोर्टलवरील georeferenced polygon.

```bash
cp control.sample.json control.json      # खऱ्या GPS ने lat/lon भरा (एक किंवा दोन बिंदू)
python3 georef_overlay.py control.json --out overlay.png --geojson plot.geojson
python3 georef_overlay.py control.json --no-imagery --geojson plot.geojson   # फक्त GeoJSON
```

GeoJSON QGIS किंवा Google Earth मध्ये थेट उघडतो.

**टाइल स्रोत** (`"tiles"` किंवा `"tile_url"`): `esri` (उपग्रह), `bhuvan` (ISRO — खाते लागते),
`osm` (रस्ते/इमारतींचा नकाशा). **OpenStreetMap कडे स्वतःची उपग्रह प्रतिमा नाही.** OSM च्या
सार्वजनिक टाइल्सना वापर-मर्यादा आहे; व्यावसायिक वापरासाठी Mapbox/MapTiler सारखा परवानाधारक
स्रोत किंवा स्वतःचा टाइल सर्व्हर घ्यावा. Esri/Google प्रतिमा वापरताना परवाना व श्रेय बंधनकारक.

## मूल्यांकन (valuation.py)

```bash
cp rates.sample.json rates.json          # दर भरा — स्क्रिप्टमध्ये कोणतेही दर आधीच नाहीत
python3 valuation.py rates.json --csv मूल्यांकन.csv
```

* **शासकीय दर** — नोंदणी व मुद्रांक विभागाचा वार्षिक बाजारमूल्य दर तक्ता (रेडी रेकनर,
  igrmaharashtra.gov.in). गाव + झोननिहाय ₹/चौ.मी. दर मिळतो. याला खुला API नाही — दर
  हाताने भरावा लागतो; तो दरवर्षी बदलतो.
* **बाजार दर** — नोंदणीकृत दस्तांवरून किंवा स्थानिक दलालांकडून. पोर्टलवरील किमती *मागणी*
  किमती असतात, व्यवहाराच्या नव्हे — त्या scrape करणे ToS विरुद्ध असते.
* `factors` — रस्ता तोंड, आकार, सामाईक वापर यासाठी गुणक. स्क्रिप्ट स्वतःहून काहीही गृहीत
  धरत नाही; प्रत्येक गुणक वापरकर्त्याने ठरवायचा.
* सामाईक तुकड्याचे (उदा. 2457/4) मूल्य धारकांत वाटून दाखवले जाते.

अहवालात हे **सूचक (indicative)** मूल्य म्हणूनच द्यावे. मुद्रांक शुल्कासाठीचे अधिकृत
बाजारमूल्य शासनमान्य मूल्यांकनकर्त्याकडूनच ठरते.
